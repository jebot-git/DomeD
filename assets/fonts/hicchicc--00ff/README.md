# 00ff pixel fonts for DomeD

Source: https://hicchicc.github.io/00ff/

Pinned website revision: 91451a311511ef023288f6efcdb95b72f2b43ef1.

These nine downloads remain under hicc’s **original license**, not SIL OFL.
The exact upstream Japanese terms are retained in LICENSE-upstream.html.
They permit modification and redistribution, prohibit selling the fonts themselves
and claiming authorship, and retain the author’s copyright. The author disclaims
warranty and responsibility. The upstream license migration notice explicitly
places these older downloads below the original-license section.

MaruMinya is packaged separately from its upstream OFL repository, alongside
the MaruMinyaHangul derivative. MaruMinyaM remains excluded. NegaTape, NegaClip and DenkiChip are
packaged separately under their own upstream OFL notices.

Only BDF files are shipped. See upstream.json for source hashes, native pixel
sizes and conversion methods. Embedded bitmap strikes are preserved exactly;
outline-only pixel fonts are rasterized in one-bit mode at the design grid.
Every mapped Unicode glyph is compared against FreeType’s source rendering,
including advances and bearings, after loading the generated BDF.
