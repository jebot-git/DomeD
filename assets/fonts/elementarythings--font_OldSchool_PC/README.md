The source of these fonts is VileR, who did the conversion work and posted it at: https://int10h.org/oldschool-pc-fonts/

Specifically:
The Ultimate Oldschool PC Font Pack < http://int10h.org/oldschool-pc-fonts/ > v2.2 // 2020-11-21

These are provided here for simplicity in .bdf and .pcf form, suitable for drop-in use in microcontrollers and similar languages that need bitmap fonts in bdf or pcf format, such as CircuitPython.

Filenames were also changed to make it more clear exactly what the size of the fonts is, and the size has been upscaled in many cases.  There are also drastically reduced character set versions, again for use on microcontrollers where storage of all types is at a premium.

For typeface copyright issues, see VileR's site (link above) and also https://en.wikipedia.org/wiki/Eltra_Corp._v._Ringer
